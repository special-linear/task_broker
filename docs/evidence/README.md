# Sanitized verification evidence

These reports preserve the measured results of the implementation staging runs. Personal hostnames are replaced with `staging.example.test`; installation and fixture UUIDs are replaced with stable `record-NNNN` labels. The native backup digest is omitted. Timings, counts, SQL plans, test outcomes, timestamps and stated limitations retain their recorded values. The demonstration CSV contains synthetic input and output.

Original reports and the screenshot remain local under ignored `artifacts/verification/` and `artifacts/private/publication-audit/originals/`. New test runs write to ignored `artifacts/private/verification/`. Review and sanitize new evidence before adding it here; raw files are never automatically copied into a release. The screenshot is excluded because it exposes fixture names and is not covered by text scanning.
